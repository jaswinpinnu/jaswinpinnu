1. Create a **public** repository named exactly `jaswinpinnu` (same as your GitHub username).
2. Upload every file in this package to the repository root, preserving folders:
   - `README.md`
   - `assets/`
   - `.github/workflows/snake.yml`
3. Commit the files to the default branch.
4. In the repository, open **Settings → Actions → General** and ensure GitHub Actions are enabled.
5. Open **Actions**, run **Generate contribution snake** once with **Run workflow**.
